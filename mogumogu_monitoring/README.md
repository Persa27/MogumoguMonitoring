# もぐもぐ監視アプリ

子供がちゃんと食べているかを監視するFlutterアプリです。

## 機能

- **リアルタイム顔検出**: カメラを使用して複数の顔を同時に検出し、画面に顔枠を表示
- **個別の唇の動き検知**: 各顔ごとに唇の動きを監視して食事をしているかどうかを判定
- **顔ごとの食事状況表示**: 各顔枠の上に「食べています」「食べていません」の状態を個別表示
- **アラート機能**: 指定時間食べていない場合に警告メッセージと音声通知
- **フロントカメラ対応**: フロントカメラ使用時の座標修正と左右反転に対応
- **カスタマイズ可能な設定**:
  - 唇の動きの検知閾値（0.1-10.0）
  - 食べていないと判断する時間（1-60秒、1秒刻み）
  - 5種類の警告音から選択可能
  - フロント/バックカメラの切り替え
- **統計機能**: 食事回数、警告回数、監視時間の表示
- **設定の永続化**: SharedPreferencesを使用して設定を保存

## セットアップ

### 前提条件
- Flutter SDK (3.8.1以上)
- Android Studio / Xcode (各プラットフォーム用)

### インストール手順

1. 依存関係のインストール:
```bash
flutter pub get
```

2. Android用の実行:
```bash
flutter run
```

3. iOS用の実行:
```bash
flutter run -d ios
```

### 権限設定

#### Android
以下の権限が `android/app/src/main/AndroidManifest.xml` に追加されています:
- `CAMERA`: カメラアクセス
- `RECORD_AUDIO`: 音声録音（音声再生用）
- `WRITE_EXTERNAL_STORAGE`: ストレージアクセス

#### iOS
以下の権限が `ios/Runner/Info.plist` に追加されています:
- `NSCameraUsageDescription`: カメラ使用許可
- `NSMicrophoneUsageDescription`: マイク使用許可

## 使用方法

1. **アプリ起動**: アプリを起動するとカメラが自動的に開始されます
2. **顔の検出**: カメラに顔を向けると緑色の枠が表示されます
3. **食事の監視**: 唇の動きが検知されると顔枠の上に「食べています」と表示されます
4. **複数人対応**: 複数の人が映っている場合、それぞれ個別に監視されます
5. **設定変更**: 右上の設定ボタンから各種設定を変更できます

### 設定項目

- **動きの閾値** (0.1-10.0): 唇の動きを検知する感度
  - 値が小さいほど小さな動きでも検知
  - 値が大きいほど大きな動きのみ検知
- **判定時間** (1-60秒): 食べていないと判断するまでの時間（1秒刻み）
- **警告音**: 判定時間経過時に再生する音声の種類
- **カメラ切り替え**: フロント/バックカメラの切り替え

## 音声ファイルのカスタマイズ

### 標準音声ファイル
アプリには以下の音声ファイルが含まれています:
- `assets/notification.mp3`: デフォルト通知音
- `assets/bell.mp3`: ベル音
- `assets/alarm.mp3`: アラーム音
- `assets/voice.mp3`: 音声メッセージ

### カスタム音声の追加（v2.1で追加）
**方法1: スマートフォン内のファイルを選択**
1. 設定画面で「カスタム音声」を選択
2. 「選択」ボタンをタップしてファイルピッカーを開く
3. MP3、WAV、M4A、AACファイルから選択
4. 設定が自動的に保存されます

**方法2: アプリ内音声ファイルの変更**
1. 音声ファイル（MP3形式）を `assets/` フォルダに配置
2. ファイル名を既存のものと同じにするか、コードを修正
3. `flutter pub get` を実行してアプリを再ビルド

### 推奨音声設定
- **ファイル形式**: MP3、WAV、M4A、AAC（スマートフォン内ファイル選択時）
- **ファイル形式**: MP3（アプリ内ファイル用）
- **品質**: 128kbps以上
- **長さ**: 1-5秒程度
- **音量**: 適度な音量（アプリ内で調整不可）

## 動きの閾値について

動きの閾値は唇の検知感度を調整する重要なパラメータです：

### 閾値の意味
- **低い値 (0.1-2.0)**: 小さな唇の動きでも「食べている」と判定
- **中程度 (2.0-5.0)**: 一般的な食事の動きを検知
- **高い値 (5.0-10.0)**: 大きな動きのみを検知

### 設定の目安
- **感度を上げたい場合**: 閾値を下げる（0.5-1.5程度）
- **誤検知を減らしたい場合**: 閾値を上げる（3.0-6.0程度）
- **子供の小さな動き**: 0.3-1.0程度
- **大人の食事**: 1.0-3.0程度

## トラブルシューティング

### カメラが起動しない
- デバイスの権限設定でカメラアクセスが許可されているか確認
- 他のアプリがカメラを使用していないか確認

### 顔検出が機能しない
- 十分な明るさがあるか確認
- カメラに顔が正面から映っているか確認
- 顔が画面の中央付近にあるか確認

### フロントカメラで左右が逆に表示される
- この問題は修正済みです（v2.0）
- 顔枠と赤い点が正しい位置に表示されます

### 音声が再生されない
- デバイスの音量設定を確認
- 音声ファイルが正しく配置されているか確認
- 他のアプリが音声を使用していないか確認

### 検知が正しく動作しない
- 動きの閾値を調整（小さくすると敏感に、大きくすると鈍感に）
- 判定時間を調整（短くすると早く警告、長くすると遅く警告）
- 照明条件を改善
